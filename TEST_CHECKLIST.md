- [ ] Extract the ZIP into a normal folder.
- [ ] Open `index.html` in Chrome or Edge with internet access.
- [ ] Confirm the map appears.
- [ ] Toggle Viking visible imagery off and on.
- [ ] Toggle MOLA hillshade off and on.
- [ ] Toggle THEMIS daytime infrared on and off.
- [ ] Toggle synthetic zones and waypoints.
- [ ] Calculate a route from West Ridge Station to Delta Science Site.
- [ ] Calculate a second route with different endpoints.
- [ ] Confirm that choosing the same endpoint is rejected with a clear message.
- [ ] Check the browser console for errors if a layer fails to load.
- [ ] Capture screenshots of the working app on your own computer.
- [ ] Record a short demo using the supplied script.
- [ ] Fill in the official submission form with accurate individual-contribution details.
- [ ] Verify the official challenge portal's current deadline and submission requirements.

Note: I have prepared the files, but this environment has not run a live browser test against NASA's tile servers. A map layer may be temporarily unavailable due to network or service conditions.
