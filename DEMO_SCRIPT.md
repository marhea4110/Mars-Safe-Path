# 2-minute demo script

**0:00–0:20 — Introduction**  
“Hello. My project is Mars Safe Path, an educational traverse-planning prototype focused on Jezero Crater, the exploration region of the Perseverance rover.”

**0:20–0:50 — NASA layers**  
“Here is the interactive Mars map. I can view three independent NASA Mars Trek products: Viking visible imagery, MOLA colour hillshade for broad topographic context, and THEMIS daytime infrared imagery. Each layer can be switched on or off.”

**0:50–1:20 — Route planning**  
“I can select a starting point and destination. The application runs A* pathfinding on a 16 by 16 demonstration cost grid and displays the suggested path alongside a direct comparison line.”

**1:20–1:45 — Explain the result**  
“The metrics show approximate map distance and the accumulated synthetic grid cost. This demonstrates how a route planner can balance distance against a modelled traversal cost.”

**1:45–2:00 — Scientific limitation**  
“The NASA map layers are visual context only. The cost grid and high-cost zones are illustrative and are not measured hazards. A future research version would derive terrain costs from a documented Jezero elevation model and validate the results.”
